# Orbit Calculator

A premium dark-mode Android calculator built with Kotlin and Jetpack Compose.

## Build

The included GitHub Actions workflow builds a debug APK whenever changes are pushed to `main`. Download the **orbit-calculator-debug-apk** artifact from the workflow run.

## Features

- Basic arithmetic, percentage, sign toggle, and decimal entry
- Elegant responsive Jetpack Compose interface
- Android 7.0+ support
